# File map

One entry per directory and per significant file: what lives there and when to touch it.

## Top level

- `README.md`: what the skill is, install, quick start, how it works, scripts, results, test rig, layout
- `runs/<round>/<slug>/`: per-site test output (git-ignored except REPORT.md, CHANGES.md)
- `package.json`: ESM, deps (playwright-core, pngjs, pixelmatch, culori), npm scripts
- `runs/.gitkeep`: keeps runs/ in git (whitelisted in .gitignore)

## Docs

- `docs/SPEC.md`: goals, architecture, capture fields, scoring rules
- `docs/USAGE.md`: how to install and use the skill, what to expect, final results

## Skill

- `skill/restyle/`: the shipped skill (self-contained)
- `skill/restyle/SKILL.md`: workflow the model follows; the only file read in full (<= 220 lines): how to work (what to read when, images, writing files), token cost per step, command table, steps that point to reference sections by `§tag`, verify loop (full/fast captures, full/delta reviews), done and stop rules
- `skill/restyle/scripts/`: capture.mjs, compare.mjs, sheet.mjs, inspect.mjs, type-scale.mjs, serve.mjs
- `skill/restyle/references/`: capture schema, spec schema, build rules, motion patterns, font substitutes, visual review, scoring; instruction files open with a "when you need this" header and `## §tag` sections read one at a time
- `skill/restyle/scripts/package.json`: deps for the installed skill (`npm install` here once): playwright-core, pngjs, pixelmatch, culori

## Skill scripts

- `skill/restyle/scripts/serve.mjs`: static server: `node serve.mjs <dir> [port]`, prints {url,port,dir,pidFile}; a given port that is busy (also a server on 127.0.0.1 or ::1 only) exits 1 with a message, never another port; no port = a free one; pid record <os temp>/restyle-serve-<port>.json; `--stop <port>` stops that server gracefully (POST with the token from its pid record; the server exits 0; kill only as a fallback; one JSON line with `graceful`, exit 1 when nothing was stopped, stale records removed)
- `skill/restyle/scripts/capture.mjs`: URL -> capture dir (capture.json restyle-capture/2, summary.md digest, shots/ (full shots rendered as each band looks in view: content-visibility forced, scroll-driven animations paused in view, blank rows filled from in-view viewport shots, <vp>-full-rest.png = scroll-0 state, shots[vp].render/blank, sections[].shot, flat content bands re-filled after the analysis, a capture still largely blank rebuilt from viewport tiles (shots[vp].blank.stitched), scroll-theme bands in their in-view colour, <vp>-full-tail-<k>.png past the 20000 px cap = shots[vp].tails) incl. <vp>-scrolled.png and type-<role>.png samples, motion/frames/ load (warm-cache reload, 5 s from first contentful paint; settle time and media-arrival lead-in recorded) + up to 4 reveals (from the wheel input, measured scroll timing, content-in-place measure; --frames-like <refCapDir>: at the reference's page positions; reveal groups get trigger provenance crossed/rest, ys, and skip when a load-driven fade is in place in its strip) + settled first-screen media sample + hover pairs); popups dismissed/hidden before measuring; hero media activity (frames.mjs sampleMedia, the code inspect.mjs activity runs: rate = share of the box changing per second on the settled page, level from rate alone, intermittent, how it moves, arrival with the load staging, most-moving region; motion inside a media box absorbed as its activity); load settle with what keeps moving after it; hover crop deltas; first-screen component crops from the fold; done.json written last (deleted and started.json written first), --wait <outDir> waits for the latest one; band-centred pass (settled colours, scroll tint with per-band states before/entering/centred); marquees also at 768/390 (short idle sample, motion.marqueesByViewport); --fast for quick 1440-only iteration; a failing viewport is retried once, a second failure exits non-zero; type.webFonts (web fonts loaded, public-catalogue verdict) and type.families[].inCatalogue via lib/font-catalogue.mjs; schema in references/capture-schema.md
- `skill/restyle/scripts/compare.mjs`: ref capture + build capture -> diff.json (restyle-diff/2): five area scores, total, ranked findings with fix sentences, health[] (HEALTH FAIL lines first in the stderr table, healthFail in the JSON line), partial flag for --fast captures; measures reveal strip content from stored frames (Chrome) when an older capture lacks it
- `skill/restyle/scripts/sheet.mjs`: <= 10 compact side-by-side ref/build sheets for the builder's self-review and the judge (fold, full-1440 in <= 4 slices (tail shots past the capture's height cap joined under the full shot), 768, 390, states = components + hover + scrolled, motion strips in rows of 5: load over one span until both sides settled (settle note + what keeps moving), zoomed moving first-screen media whenever either side moves (large boxes by their most-moving half), reveals from the wheel input; motion sheets fit the remaining budget) -> PNGs + sheets.json; --ref-only <refCapDir> <outDir>: reference contact sheets
- `skill/restyle/scripts/inspect.mjs`: builder measuring tools, one JSON line each: color/crop (PNG or JPEG regions), overflow (incl. clipped[]: text/media cut at the viewport edge, the capture's own check), style (several selectors share one page load; each match scrolled into view and settled first, so elements below the first screen report their in-view state; `atTop` = what differed at scroll 0), bands <url> [width] (capture browser settings, blocked flag), activity <url> [--box] (first-screen media activity in ~10 s, the capture's own measure), fontmatch <refCapDir> --role <role> [--brief] (visual font matching), get <capDir> <path> [--depth N] (one capture.json value by dot path, big values cut with a note); style says why 0 elements matched
- `skill/restyle/scripts/type-scale.mjs`: design-spec.json -> type-scale CSS (exits 1 when a source:"google" family is not in the public catalogue, warns when only the offline subset was checked; vars per breakpoint range + .t-<role> classes, font axes as font-variation-settings / optical sizing, Google Fonts css2 URL), exact at 390/768/1440, steps where roles switch font/case, band headings with their role's fontmatch size factor (a role without its own fontmatch entry takes its slot's nearest matched role's factor; a band at a heading role's reference px takes that role's px; headRole may name the role it is set in (the band then takes that role's px, in any band role), headRole figure/quote/label/wordmark skips the band; cta slot; opsz only when axes.opsz asks; warns when a band heading is > 15% from every heading role and headRole is absent or "heading"); --out <file> writes the linked type-scale.css

## Test rig

- `harness/`: test rig: sites.json, score.mjs, report.mjs, pipeline.mjs, judge-prompt.md, check-*.mjs
- `harness/sites.json`: 23 reference sites (5 pilot / 15 rest / 3 holdout) with fictional briefs
- `harness/judge-prompt.md`: blind judge instructions, anchors, output JSON format
- `harness/score.mjs`: diff.json + judge.json -> score.json (0.5/0.5 per area, weighted total, pass >= 8.5 and no compare health fail (healthFail[]), merged issues)
- `harness/report.mjs`: runs/<round>/*/score.json -> runs/<round>/REPORT.md (table, averages, lowest area, frequent issues)
- `harness/pipeline.mjs`: `ref <round> <slug>` (capture, --from <round> copy, or --from-build: the builder's snapshot) and `eval <round> <slug>` (builder's snapshot as reference when present, serve build, capture --frames-like, compare, sheets via skill/restyle/scripts/sheet.mjs; an older reference snapshot is backfilled first)
- `harness/backfill-ref.mjs`: brings a pre-round-5 reference capture copy up to date from its stored frames and shots (media rate/hot/activity, load settle + keepsMoving, hover crop deltas, first-screen component crops from the fold); never edits a builder snapshot in place
- `harness/lib/run.mjs`: harness process helpers: free port, serve.mjs start/stop (Windows-safe), node child runs, last JSON line
